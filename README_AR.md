# قارئ كتالوج «النخبة للإلكترونات» (قراءة فقط)

يفتح هذا المشروع **الصفحات العامة** لموقع المتجر (ما يراه أي زائر) بطلبات GET فقط، صفحة كل 1.1 ثانية تقريباً، ثم ينشر النتيجة ملفات JSON ثابتة على GitHub Pages ليقرأها تطبيق الهاتف. لا يسجّل دخولاً ولا يرسل أي نموذج ولا يكتب شيئاً في الموقع أو في أودو.

- حالة التوفر مطابقة لما يعرضه الموقع: «متوفر» أو «نفدت الكمية». (الموقع لا يعرض «آخر الكميات».)
- الدورة: كل ساعة يقرأ قائمة المنتجات (نحو 61 صفحة) ويعيد فحص 300 صفحة منتج الأقدم فحصاً، فتتجدد حالة كل منتج كل 4 ساعات تقريباً. المنتجات الجديدة تُفحص فوراً. أول تشغيل يقرأ كل المنتجات ويستغرق نحو 30 دقيقة.
- إن طلب الموقع منا التوقف (رد 403 أو 429) أو وجدنا عدداً قليلاً جداً من المنتجات، فلا يُنشر شيء وتبقى آخر بيانات سليمة على الإنترنت.
- تشغيل الاختبارات: `pip install -r crawler/requirements.txt pytest` ثم `python -m pytest -q tests`.

الملفات المنشورة: `v1/catalog.json` و`v1/products/<رقم>.json`.
